# Jairo Assistant — demostración familiar

Esta es una **demostración pública sin cuentas** para evaluar el diseño con familiares. Los datos se almacenan únicamente en el navegador de cada persona; **no se sincronizan** y no hay recordatorios automáticos ni integración con WhatsApp.

**No introducir nombres completos, teléfonos, medicamentos reales, diagnósticos, decisiones privadas ni otros datos sensibles.** Usar únicamente información ficticia.

## Publicar en GitHub Pages
1. Crear un repositorio público nuevo llamado `jairo-assistant-demo` (sin archivos iniciales).
2. Seleccionar **Add file → Upload files** y subir `index.html` y `README.md` (extraídos del ZIP). Pulsar **Commit changes**.
3. Abrir **Settings → Pages**; en **Build and deployment**, elegir **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guardar.
4. Abrir la URL que muestre GitHub Pages y compartirla solo para evaluar la interfaz. La página será públicamente accesible aunque se comparta solo con familiares.

**No subir el servidor de pruebas ni archivos `.env`, contraseñas, claves API o información médica.** La aplicación compartida con inicio de sesión, base de datos y WhatsApp es una fase posterior, no incluida en esta demo.
